# JS Exercise 21 – Array reduce() Method

**Description:**  
This exercise practices using the `reduce()` method to aggregate array values in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `numbers` with values `[1, 2, 3, 4]`.  
- Use the `reduce()` method to multiply all numbers in the array.  
- Log the result to the console.
