# JS Exercise 25 – Spread & Rest Operators

**Description:**  
This exercise practices using the **spread operator** to combine arrays and the **rest parameter** in functions to handle multiple arguments.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Tasks:**  
1. **Combine Arrays with Spread Operator**  
   - Arrays: `[1, 2, 3]` and `[4, 5, 6]`  
   - Combine them into a single array using the spread operator.  
2. **Multiply Numbers with Rest Parameter**  
   - Create a function `multiply(...numbers)` that takes any number of arguments and returns their product.  
   - Use `reduce()` inside the function.
