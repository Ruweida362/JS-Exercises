# JS Exercise 23 – Object Destructuring

**Description:**  
This exercise practices using object destructuring in JavaScript to extract property values.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an object `car` with properties:  
  - `make`  
  - `model`  
  - `year`  
- Use object destructuring to extract `make` and `model`.  
- Log the extracted values to the console.
