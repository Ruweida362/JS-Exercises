# JS Exercise 14 – Do-While Loop

**Description:**  
This exercise practices using the `do...while` loop in JavaScript to repeatedly prompt the user until a condition is met.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Write a `do...while` loop that asks the user to enter a number greater than `10`.  
- Repeat the prompt until the user enters a valid number.  
- Log the entered number to the console.
