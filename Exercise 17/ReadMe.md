# JS Exercise 17 – If-Else If-Else Statement

**Description:**  
This exercise practices using `if-else if-else` statements in JavaScript to handle multiple conditions.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create a variable `temperature`.  
- Use `if-else if-else` statements to log:  
  - `"Very cold"` if temperature < 0  
  - `"Cold"` if temperature between 0 and 15  
  - `"Warm"` if temperature between 16 and 25  
  - `"Hot"` if temperature > 25
