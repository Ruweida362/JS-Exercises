# JS Exercise 08 – Objects

**Description:**  
This exercise practices creating and accessing objects in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an object `car` with properties:  
  - `make` – `"Toyota"`  
  - `model` – `"Land Cruiser"`  
  - `year` – `2018`  
- Log the object and each property individually to the console.
