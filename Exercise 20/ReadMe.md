# JS Exercise 20 – Array map() Method

**Description:**  
This exercise practices using the `map()` method to transform arrays in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `fruits` with values `["apple", "banana", "cherry"]`.  
- Use the `map()` method to create a new array `lengths` that contains the length of each fruit string.  
- Log the `lengths` array to the console.
