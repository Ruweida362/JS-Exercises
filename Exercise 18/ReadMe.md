# JS Exercise 18 – Ternary Operator

**Description:**  
This exercise practices using the ternary operator (`? :`) in JavaScript for conditional expressions.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create a variable `grade` with a value (e.g., `65`).  
- Use the ternary operator to check:  
  - If `grade >= 60`, log `"Pass"`  
  - Otherwise, log `"Fail"`.
