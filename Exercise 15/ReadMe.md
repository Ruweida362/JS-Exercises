# JS Exercise 15 – For...in Loop

**Description:**  
This exercise practices using the `for...in` loop to iterate over object properties in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `people` with multiple objects. Each object should have:  
  - `name`  
  - `age`  
  - `city`  
- Use a `for...` loop to iterate over the array.  
- Inside it, use a `for...in` loop to log each property and value of the objects.  
- Separate each person with a line (`------`).
