# JS Exercise 12 – For Loop with Arrays

**Description:**  
This exercise practices using a `for` loop to iterate over arrays in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `fruits` containing `"apple"`, `"banana"`, and `"cherry"`.  
- Use a `for` loop to log each item in the array to the console.
