# JS Exercise 02

**Description:**  
This exercise practices JavaScript comparison operators using variables with different types.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Declare two variables: `a = 15` (number) and `b = "15"` (string).  
- Use all comparison operators and log the results
