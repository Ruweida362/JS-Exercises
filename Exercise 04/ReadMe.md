# JS Exercise 04 – Functions

**Description:**  
This exercise practices creating functions in JavaScript, including both normal functions and function expressions.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
1. Create a function named `add` that takes two numbers and returns their sum.  
2. Use a function expression to do the same.  
3. Test your functions with different inputs and log the results.
