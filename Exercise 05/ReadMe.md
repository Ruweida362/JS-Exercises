# JS Exercise 05 – Arrow Functions

**Description:**  
This exercise practices converting a normal function into an arrow function in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Convert the normal `add` function to an arrow function.  
- The function should take two numbers as arguments and return their sum.  
- Test your function with different inputs and log the results.
