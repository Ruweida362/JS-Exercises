# JS Exercise 07 – Array Methods

**Description:**  
This exercise practices using JavaScript array methods such as `push` and `shift`.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
1. Create an array `colors` with values `"Blue"`, `"Black"`, `"Orange"`.  
2. Add a new color `"Green"` to the end using `push()`.  
3. Remove the first color using `shift()`.  
4. Log the array after each operation.
