# JS Exercise 03

**Description:**  
This exercise practices JavaScript logical operators using boolean variables.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create two boolean variables:  
  - `isSunny`  
  - `isWeekend`  
- Use logical operators to check if you can go to the beach (both must be true) and log the result.
