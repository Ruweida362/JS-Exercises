# JS Exercise 34: Add and Remove Elements

This project demonstrates how to add and remove HTML elements using JavaScript.

* `createElement()` creates a new list item.
* `appendChild()` adds the item to the student list.
* `removeChild()` removes the last item.
* Buttons call the `addItem()` and `removeItem()` functions.

## Run

Open `index.html` and click the buttons to add or remove students.
