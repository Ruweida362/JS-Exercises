# JS Exercise 24 – Default Parameters

**Description:**  
This exercise practices using default parameters in JavaScript functions.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create a function `calculateArea(width, height)` that calculates the area of a rectangle.  
- Set the default value of `height` to `width` (to handle squares).  
- Log the result for both a rectangle and a square.
