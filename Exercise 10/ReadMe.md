# JS Exercise 10 – Objects in Arrays

**Description:**  
This exercise practices using arrays of objects in JavaScript and accessing object properties.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `library` containing multiple book objects. Each object should have:  
  - `title`  
  - `author`  
  - `year`  
- Log the title of the first book.  
- Log the author of the second book.
