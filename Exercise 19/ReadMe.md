# JS Exercise 19 – Array forEach Method

**Description:**  
This exercise practices using the `forEach()` method to iterate over arrays in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `numbers` with values `[1, 2, 3, 4, 5]`.  
- Use the `forEach()` method to log each number to the console.
