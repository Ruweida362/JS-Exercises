# JS Exercise 11 – For Loop

**Description:**  
This exercise practices using the `for` loop in JavaScript to iterate through a sequence of numbers.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create a `for` loop that counts from `1` to `50`.  
- Log each number to the console.
