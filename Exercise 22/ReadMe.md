# JS Exercise 22 – Array Destructuring

**Description:**  
This exercise practices using array destructuring in JavaScript to extract values.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array `colors` with values `["red", "green", "blue"]`.  
- Use array destructuring to extract the first and third elements.  
- Log the extracted values to the console.
