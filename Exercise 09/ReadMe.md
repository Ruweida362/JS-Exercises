# JS Exercise 09 – Object Methods

**Description:**  
This exercise practices creating methods inside objects in JavaScript.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an object `car` with properties:  
  - `make` – `"Toyota"`  
  - `model` – `"Land Cruiser"`  
  - `year` – `2018`  
- Add a method `start()` that logs `"The Car has Started"` to the console.
