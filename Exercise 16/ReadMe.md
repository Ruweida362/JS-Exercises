# JS Exercise 16 – If-Else Statement

**Description:**  
This exercise practices using `if-else` statements in JavaScript to make decisions based on conditions.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create a variable `score` with a value (e.g., `60`).  
- Use an `if-else` statement to check:  
  - If `score >= 50`, log `"You passed!"`.  
  - Otherwise, log `"You failed"`.
