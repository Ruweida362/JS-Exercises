# JS Exercise 06 – Arrays

**Description:**  
This exercise practices using arrays in JavaScript and accessing array elements.

**Files:**  
- `index.html` – HTML file linking to the JS script  
- `script.js` – JavaScript code for the exercise

**Task:**  
- Create an array named `colors` with values: `"Blue"`, `"Black"`, `"Orange"`.  
- Access each element by its index and log it to the console.
